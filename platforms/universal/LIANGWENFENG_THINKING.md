# 梁文锋式创新思维方法论

> **将 DeepSeek 创始人梁文锋的创新思维模式系统化为可复用的 AI 编程技能。**

## 一句话

**"找到隐藏结构 → 稀疏化关键路径 → 数学化量化 → 自监督进化 → Agent 化协作"**

## 五大原则速查

### 原则 1: 寻找隐藏结构
> 不是检查更多，而是找到不变量。

审查代码时先问：系统公开宣称了什么保证？这些保证能否量化为不变量？沿着不变量追踪代码，每个分支都保证了吗？

⚠️ 警惕：`except: pass`、硬编码默认值`return 0.80`、`TODO`注释

### 原则 2: 稀疏化思维
> 20% 的要素承载了 80% 的信息。

按"影响 × 频率"排序，前 20% 是关键路径，投入 100% 资源。

⚠️ 警惕：同一模型多处独立加载、单例已定义未使用、协议重复定义

### 原则 3: 数学化力量
> 度量的才能优化。

将质量属性映射到量化指标 → 建立决策阈值 → 检查度量结果是否被实际用于决策。

### 原则 4: 自监督进化
> 系统应该越运行越好。

三段式闭环诊断：反馈产生了？→ 送达了？→ 参数变更了？三步缺一则断裂。

### 原则 5: Agent 化思维
> 让每个实体都有智能。

Agent 化三条件：有状态、有行为变异、有局部性。检查对称性是否缺失。

```markdown

### 1. 隐藏结构分析
- **系统不变量**: [3-5个]
- **脆弱点**: [位置+风险等级]

### 2. 稀疏化分析
- **关键路径 (20%)**: [列表]
- **发现的浪费**: [位置+浪费量+节省预估]

### 3. 数学化审计
- **已有指标**: [列表]
- **缺失指标**: [列表]

### 4. 闭环诊断
- **回路状态**: [闭合/断裂]
- **修复建议**: [如何闭合]

### 5. Agent 化评估
- **可Agent化实体**: [列表]
- **对称性**: [通过/缺失]

### 6. 优先级清单
| 优先级 | 行动 | 影响 | 工作量 |
|--------|------|------|--------|
| 🔴 | ... | ... | ... |
| 🟡 | ... | ... | ... |
| 🟢 | ... | ... | ... |
```
